# User Behavior Prediction

A Google Shopping user behavior analysis and purchase prediction project.

## Project Objectives

- Large-scale user behavior data processing
- Data quality validation and preprocessing
- Multi-dimensional feature engineering
- Exploratory data analysis
- Purchase behavior prediction
- Model comparison and evaluation

## Project Structure

- `src`: reusable project source code
- `tests`: unit and integration tests
- `scripts`: executable project workflows and utilities
- `configs`: project and model configuration files
- `docs`: weekly reports, research notes, and formal reports
- `data`: raw, interim, and processed datasets
- `results`: generated figures and tables
- `notebooks`: exploratory analysis notebooks

## Branch Strategy

- `main`: stable version
- `dev`: development integration branch
- `feature/*`: feature development branches

## Data

Large raw datasets and generated data artifacts are not committed to the
repository. Keep local data under the appropriate `data` subdirectory and
retain only the tracked `.gitkeep` files in Git.
